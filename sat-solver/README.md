# SAT SOLVER

### Para compilar:
 `gcc -Wall -o satsolver SAT_solver_ed.c`

### Para utilizar:

Linux/WSL `./satsolver arquivo.cnf`


### Arquivos:
- SAT_solver_ed.c         -> Código para verificar se as equações boleanas serão satisfaziveis
- *.cnf                   -> Arquivo DIMACS com equações.
