# Lista X Arvore de Busca Binária

### Para compilar:
 `gcc -Wall -o listaxabb listaXabb.c`

### Para utilizar:

Linux/WSL `./listaxabb`

### Para Plotar o Gráfico:

>Necessário ter o **R-base** instalado

`Rscript plot.R`

### Arquivos:
- listaXabb.c         -> Gera numeros randomizados e salva no arquivo "comparacoes_n.csv"
- plot.R              -> Utiliza os valores do arquivo "comparacoes_n.csv" para gerar o gráfico.
